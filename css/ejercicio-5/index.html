La propiedad display

Observa cómo cambia la posición de cada elemento.

display: block

div 1 (block)
div 2 (block)
div 3 (block)

display: inline

span 1 (inline) span 2 (inline) span 3 (inline)

display: inline-block

div 1 (inline-block)
div 2 (inline-block)

display: none

span oculto

El elemento con display: none no aparece y tampoco ocupa espacio.

Diferencias

block: ocupa una línea completa.

inline: se coloca junto a otros elementos, pero no permite cambiar su ancho y alto.

inline-block: se coloca junto a otros elementos y permite definir su ancho y alto.

none: oculta el elemento.
